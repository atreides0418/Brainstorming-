# 단계적 브레인스토밍 시스템 — 소개 페이지

AI는 완성된 답을 주지 않는다. 질문과 재료만 만들고, 채우는 건 언제나 사용자다.
단계적인 브레인스토밍을 통해 창의적인 발상을 내도록 돕는 서비스의 소개(랜딩) 페이지입니다.

## 실행 방법

빌드 도구 없이 순수 HTML/CSS/JS로 만들어졌습니다. `index.html`을 브라우저에서 더블클릭해 바로 열면 됩니다.

```bash
# 또는 로컬 서버로 열고 싶다면
npx serve .
```

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 페이지 구조와 콘텐츠 (문제 정의, 시스템 흐름도, 핵심기능, 부가기능, 차별점, 기대효과) |
| `style.css` | 스타일 — 밝은 블루 그라데이션 히어로, 카드 기반 레이아웃 |
| `script.js` | 인터랙션 — 시작 지점 진단 위젯, 서랍 열기/닫기, 스크롤에 따른 내비게이션 강조 |

## 배포

빌드 커맨드가 필요 없는 정적 사이트입니다. Vercel 등에 저장소를 그대로 연결하면 별도 설정 없이 배포됩니다.
